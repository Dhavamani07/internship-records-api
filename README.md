# Internship Records API

A REST API to manage internship records using Node.js, Express.js and SQLite.

## Features
- Get all internship records
- Get an internship by ID
- Create a new internship
- Update internship details
- Delete internship records
- Input validation and error handling
- Persistent SQLite database

## Installation
1. Install Node.js.
2. Clone this repository.
3. Run `npm install`.
4. Run `node server.js`.
5. Open `http://localhost:3000`.

## API Endpoints

| Method | Endpoint | Purpose |
|---|---|---|
| GET | /internships | Get all records |
| GET | /internships/:id | Get one record |
| POST | /internships | Add a record |
| PUT | /internships/:id | Update a record |
| DELETE | /internships/:id | Delete a record |
